# 부산대학교 인문사회계열 생성형 AI 활용 인식 조사 분석 앱

본 프로젝트는 부산대학교 인문사회계열 1학년 학생들의 '생성형 AI 활용 인식' 설문 데이터를 업로드하고, 정제 및 시각화 분석을 수행할 수 있는 Streamlit 기반의 멀티페이지 웹 애플리케이션입니다.

---

## 📁 폴더 및 파일 구조

프로젝트 루트 디렉토리는 다음과 같이 구성되어야 합니다.

```text
my_streamlit_app/
│
├── Home.py                 # 메인 홈 화면 (파일 업로드 및 안내)
├── survey_raw.csv          # 설문지 원본 CSV 파일
├── requirements.txt        # 필요 라이브러리 목록
├── README.md               # 프로젝트 설명서
│
└── pages/                  # 서브 페이지 폴더
    ├── 1_데이터_정제.py     # 데이터 정제 및 이상치·결측치 처리 페이지
    └── 2_그래프_분석.py     # 시각화 및 통계 분석 페이지
```

---

## 🛠️ 설치 및 실행 방법

### 1. 패키지 설치
터미널(또는 파이참 터미널)에서 프로젝트 폴더로 이동한 후 아래 명령어를 실행하여 필요한 패키지를 설치합니다.
```bash
pip install -r requirements.txt
```

### 2. 앱 실행
아래 명령어를 입력하여 Streamlit 앱을 실행합니다.
```bash
streamlit run Home.py
```

## 🚀 주요 기능

1. **홈 화면 (`Home.py`)**
   - 연구 개요 및 이용 안내 제공
   - 구글 설문지 원본 CSV(`survey_raw.csv`) 파일 업로드 기능 (`st.session_state["raw_df"]` 저장)

2. **데이터 정제 페이지 (`pages/1_데이터_정제.py`)**
   - **열 제목 축약:** 타임스탬프, 성별, 학년, 소속단과대학, AI사용시간, 문항별 레이블(`Q1_활용빈도` 등), 서술형으로 간결하게 변경
   - **중복 제거:** 타임스탬프를 제외한 모든 열이 동일한 중복 응답 제거
   - **학년 표기 통일:** 학년 데이터를 숫자로 변환 (예: '1학년', '일학년' $\rightarrow$ `1`)
   - **단과대학 분류:** 텍스트 매칭을 통해 인문, 사회과학, 경제통상, 경영, 사범, 기타 대학으로 분류
   - **이상치 처리:** '1시간 30분' $\rightarrow$ `90` (분 단위 숫자 변환) 및 사이드바 슬라이더를 통한 허용 범위 설정
   - **결측치 처리:** 열별 빈칸 수 확인 및 '그대로 두기' / '행 삭제' 옵션 제공
   - **점수 역산:** 역문항 재계산 (`Q6R` 생성)
   - **내보내기:** 정제된 데이터를 `st.session_state["clean_df"]`에 저장하고 CSV 파일로 다운로드 가능

3. **그래프 분석 페이지 (`pages/2_그래프_분석.py`)**
   - **요약 지표:** 유효 응답 수, 평균 AI 사용 시간, AI 윤리의식 평균 제공
   - **정제 전후 비교:** 단과대학별 응답자 수 변화 비교 (가로 막대 차트)
   - **탭별 다차원 분석:**
     - *응답자 구성:* 성별, 학년, 단과대학별 분포 시각화
     - *문항별 평균:* 설문 문항별 평균 점수 산출 및 표 제공
     - *집단 비교:* 학년별·단과대학별 평균과 인원 수 집계
     - *사용 시간과 점수:* AI 사용 시간과 문항 간의 관계 분석
